# Primos Launcher Hub

A standalone, responsive launcher-style website prototype.

## Run it
Open `index.html` in a modern browser. No build tools or server are required.

## Included
- Responsive black/custom gaming interface
- Overview dashboard
- Minecraft Java version preference selector
- Local mod and resource-pack checklists
- Browser-local settings and JSON export

## Important limitations
This is a website interface, not a Minecraft launcher. It does not download or install Minecraft, run Java, authenticate Minecraft accounts, or launch a game. A compatible launcher/runtime is still required for actual Java Edition gameplay, especially on iOS.

The demo stores preferences in the browser's local storage when "Remember my setup" is enabled. It does not upload data to a server. For a genuinely private hosted link, deploy it to a hosting provider with access control enabled; a public static URL alone is not private.
